# LOLI — Migas, 5mewmet
#
# Строки с # и // игнорируются. Строки вида [Припев] тоже игнорируются.
# Пока здесь нет ни одной строки без #, сайт сам подтянет текст с lrclib.net.
#
# ───────────── СИНТАКСИС ─────────────
#
# {fx1,fx2} в начале строки      → эффекты на всю строку
# слово{fx1,fx2}                 → эффекты на одно слово
# <несколько слов>{fx1,fx2}      → эффекты на группу слов
# #ff3d7f внутри {}              → свой цвет (строго 6 hex-символов)
# Пробелы и запятые внутри {} равнозначны: {caps red shake} = {caps,red,shake}
# Всё то же самое работает в .lrc: [00:12.34]{center,hype} текст строки
#
# Если у строки нет ни одного эффекта, она оформляется случайно, как раньше.
# Если хоть один эффект есть, случайное оформление отключается.
#
# ───────────── ЦВЕТА (10 + hex) ─────────────
# lime cyan pink red gold white violet orange blood ice  #rrggbb
#
# ───────────── СТИЛЬ (21) ─────────────
# outline     контур без заливки
# thin        тонкий шрифт
# bold        жирный с обводкой
# italic      курсив
# caps        КАПС
# spaced      р а з р я д к а
# tight       сжатые буквы
# strike      зачёркнуто
# under       подчёркнуто
# mirror      зеркально
# upside      вверх ногами
# tilt        наклон
# blurred     размыто
# ghost       почти прозрачно
# dim         приглушено
# quiet       тихий курсив с разрядкой
# mono        моноширинный шрифт
# longshadow  длинная тень цветом строки
# neon        неоновое свечение
# glow        свечение от баса
# hot         подсветка слова цветом строки
#
# ───────────── РАЗМЕР (4) ─────────────
# huge big small tiny
#
# ───────────── ЦВЕТОВЫЕ АНИМАЦИИ (2) ─────────────
# rainbow     радуга бежит по буквам
# grad        переливающийся градиент lime → cyan → pink
#
# ───────────── ДВИЖЕНИЕ, ПОСТОЯННО (18) ─────────────
# shake       тряска
# jitter      дрожание каждой буквы
# wave        волна по буквам
# bounce      подпрыгивает
# float       плавает
# pulse       пульсирует
# beat        качается под бочку (реагирует на звук)
# bass        сильнее beat + свечение (реагирует на звук)
# spin        крутится
# swing       маятник
# wobble      желе-перекос
# rubber      резиновое сжатие
# heartbeat   сердцебиение
# drunk       пьяный дрейф
# breathe     дышит
# flicker     мерцает как лампа
# chroma      RGB-расслоение
# glitch      глитч-срезы pink/cyan
#
# ───────────── ПОЯВЛЕНИЕ (12) ─────────────
# type        печатается по буквам
# scramble    хакерский перебор символов
# drop        падает сверху с отскоком
# rise        всплывает снизу
# pop         выпрыгивает
# fade        медленно проявляется
# blurin      из размытия
# stretch     сжимается из растянутого
# fall        буквы сыплются сверху
# slam        впечатывается в экран + тряска
# zoomin      вылетает из глубины
# late        появляется с опозданием
#
# ───────────── ИСЧЕЗНОВЕНИЕ (5) ─────────────
# explode     буквы разлетаются
# melt        стекает вниз
# burn        сгорает
# evaporate   испаряется вверх
# collapse    буквы падают
#
# ───────────── ТОЛЬКО ДЛЯ СТРОКИ (12) ─────────────
# center      по центру экрана
# straight    без 3D-наклона
# stack       каждое слово с новой строки (по центру)
# solo        убрать все остальные строки
# hold        держится дольше
# quick       исчезает быстрее
# flash       вспышка экрана цветом строки
# shakescreen тряска всего сайта
# invert      инверсия всего экрана на долю секунды
# blackout    сайт затемняется, остаётся только текст
# echo        расходящиеся эхо-копии строки
# karaoke     строка заливается цветом по мере пения
#
# Итого: 84 эффекта + 8 пресетов.
#
# ───────────── ГОТОВЫЕ ПРЕСЕТЫ ─────────────
# scream   = caps huge shake red flash shakescreen slam
# whisper  = quiet small fade evaporate
# hype     = caps beat neon bass pop
# dream    = blurin float dim ice evaporate
# horror   = blood flicker glitch melt
# chaos    = scramble jitter chroma explode
# hook     = center straight caps big karaoke beat echo
# outro    = center straight fade dim evaporate hold
#
# ───────────── КАК ДЕЛАТЬ КРАСИВО ─────────────
# Интро / первая строка       {solo,blackout,center,type,neon}
# Обычный куплет              1–2 слова на строку с эффектами, остальное без них
# Важное слово в куплете      слово{hot,pop}  слово{caps,glitch}  слово{scramble,cyan}
# Перед припевом              {center,whisper,straight}
# Первая строка припева       {hook,flash,solo}
# Остальные строки припева    {hook}
# Удар / дроп                 {scream,invert}
# Ник артиста                 <Migas>{grad,caps,slam}  <5mewmet>{neon,violet,drop}
# Мат или панчлайн            слово{red,shake,explode}
# Протяжная гласная           слово{wave,spaced,karaoke}
# Бридж                       {dream,center}
# Последняя строка трека      {outro,solo,blackout}
#
# Не вешай движение на каждое слово: 2–3 акцента на строку смотрятся лучше,
# чем 10 эффектов разом. Появление + постоянное движение + исчезновение —
# максимум одного вида каждого на слово.
#
# ───────────── ПРИМЕР ОФОРМЛЕНИЯ (вымышленные строки) ─────────────
# {solo,blackout,center,type,neon} первая строка трека
# обычная строка где одно слово{hot,pop} выделено
# <вот эти слова>{caps,glitch} и хвост строки
# {hook,flash} строка припева
# {scream} УДАР
# {outro} конец
